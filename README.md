# Twitch Theater Mode Sidebar

Theater mode hides the followed-channels list. This puts it back — as a slide-out that appears
when you push your mouse into the left edge of the screen, and gets out of the way again the
moment you leave.

## Install

1. Install [Tampermonkey](https://www.tampermonkey.net/) or [Violentmonkey](https://violentmonkey.github.io/).
2. Open [`TwitchTheaterModeSidebar.user.js`](TwitchTheaterModeSidebar.user.js) and click **Raw** — your manager will offer to install it.
3. Open a stream and enter theater mode.

Or install from [Greasy Fork](https://greasyfork.org/en/scripts/584623-twitch-theater-mode-sidebar).

## Features

- Move the mouse to the left edge in theater mode to reveal the sidebar.
- Shows your followed channels with live status, viewer counts and current game — cloned
  straight from Twitch's own nav, so it stays accurate.
- Move away or press **Esc** to dismiss it.
- Detects entering and leaving theater mode automatically.

## Using it

1. Open any stream on Twitch.
2. Enter theater mode (the button below the player).
3. Move the mouse to the far left edge.
4. Click a channel to switch instantly.

## Notes

- Only active in theater mode — it does nothing during normal browsing.
- Works alongside BTTV and other Twitch extensions.

## Applies to

`twitch.tv`
